# 用户试用与正式发布门槛

当前：未签名Windows开发包。只完成构建/打包不等于可发布或业务验收。

- 用户配置邮箱→明确试发→实际收件确认；不在报告中暴露授权码。
- 单个真实Codex/Claude Code版本接入、宿主信任/重载、正常结束/错误/子代理/普通JSON和后台噪声检查。
- Codex 备用接入：指定实例无既有 Hook 入站且整个 spool 为空才能首次启用，共享锁下初始化后完成来源独占；有历史拒绝在线切换，重启保持来源、故障不自动回退 Hook；无已完成历史补发、基线进行中任务可跟踪、ACK 后游标/重启去重、主会话普通 JSON 保留、子代理和内部阶段不通知、结构来源过滤、正文匹配/开关、数据库或版本/schema 失配降级；只读客户端数据库。
- 关闭GUI独立通知、登录恢复、休眠唤醒、静默时段与断网恢复。
- 在途SMTP未知结果不自动重发、升级中并发Hook、维护旧GUI写入拒绝、中断升级恢复、消费后降级拒绝。
- 安装重入、服务归属冲突、卸载保留数据凭据与用户改过的Hook。
- A机器迁往B机器时先确认源端停发，再启用目标端；不复制机器绑定、凭据或历史队列。
- 干净Windows10 22H2/Windows11 x64、WebView2缺失提示与离线安装；macOS/Linux原生实现和实机验收均待办。
- 正式发行另需发布者公钥、私钥隔离签名、OS代码签名、可信分发、签名升级/回滚实证及审批；不能用开发包或SHA256清单代替。

上述未执行项留给用户后续验证；本轮未自动运行测试活动、安装后台、实际发信、重启客户端或系统。

备用接入边界：启用后外部导入/替换 Codex 历史数据库不受支持，秒级时间无法可靠区分同秒导入与实时完成；正常同秒新任务不能被误删。结构 guardian 和精确 `respire-memory-worker` originator 按来源排除，子代理及内部阶段按通知范围排除；不以普通 JSON 或前台讨论关键词识别后台来源。尚无真实 Respire 持久记录正例实测，不宣称全部来源覆盖。

邮件内容专项：正文开关开启时核对同 thread/turn/item 的提问与回答，关闭时不读取对应正文；缺失不跨轮补造。核对项目/会话主题、时间与单事件展示。Respire 来源过滤须有可靠证据，保留主会话正常 JSON，抑制子代理和内部阶段；实际收件不等于这些字段和分类均通过。

最新通知策略专项：主会话最终回复正常通知；子代理、内部阶段及 Respire 不通知；项目名匹配 Codex 桌面标签、主会话标题不被昵称替代；旧邮件格式保持；恢复后历史 suppressed 不补发。可靠阻塞提醒仍待接入，不以此为由宣称只能全暂停。
