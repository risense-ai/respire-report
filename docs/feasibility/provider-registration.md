# 发行者注册与外部门槛

本轮没有访问真实邮箱凭据、创建 OAuth 应用、生成发布私钥、修改客户端 Hook 或向外部发信。注册信息属于发行者责任；用户没有私密输入前不假设具备真实凭据。

| 项目 | 责任人 | 状态 | 放行证据 |
| --- | --- | --- | --- |
| SMTP 真实账户与供应商能力 | 用户私密配置；发行者维护预设 | not_run | 单独授权后由私密入口输入授权码/口令；至少一封真实收件证据；不放到参数/日志 |
| OAuth 公共客户端注册（如后续供应商采用 OAuth） | 发行者待指定 | blocked | 确认应用归属、客户端类型/ID、redirect URI、PKCE、最小权限、审核与测试用户；桌面端不内置 client secret |
| OAuth 授权/刷新令牌存储 | 后续凭据/供应商实现 | not_run | 原生安全存储读回，撤销/过期/锁定错误分类；本轮随机条目不替代真实 OAuth 流程 |
| Windows 代码签名 | 发行者待指定 | blocked | 证书归属、发布环境安全托管、时间戳和干净机器验签 |
| macOS Developer ID / 公证 | 发行者待指定 | blocked | 团队标识、签名/公证流程和实机 Gatekeeper 验证 |
| Tauri 更新签名 | 发行者待指定 | blocked | 发布私钥保管人、产品内置公钥、有效清单和篡改拒绝测试；独立于操作系统签名 |
| 发行渠道与权限 | 发行者待指定 | blocked | 可审计安装包来源、受信更新地址、权限/回滚/卸载策略 |
| 登录任务/LaunchAgent/systemd 用户服务 | 后续平台/打包实现 | not_run | 当前用户入口注册、GUI 退出后运行、登录恢复和卸载清理实测 |

任何未具备的发行材料均不使用临时共享密钥或未签名更新绕过。当前 M0 允许继续实现离线核心及本机平台功能；不意味着允许宣称真实供应商登录、发布签名或自动更新已经可用。
